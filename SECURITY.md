# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| **v1.2.x** (Latest) | ✅ Active |
| **< v1.2.0** | ❌ Deprecated |

---

## Reporting a Security Vulnerability

If you discover a security vulnerability or critical defect in this project:

1. **Do not open a public issue.**
2. Send a detailed report to the repository maintainer via the [GitHub Security Advisory](https://github.com/Kero309x/anghamiplus-patches/security/advisories) feature, or contact via [GitHub profile](https://github.com/Kero309x).
3. Include clear reproduction steps and a description of the potential impact.

Maintainers will respond promptly to review, triage, and patch the report.
